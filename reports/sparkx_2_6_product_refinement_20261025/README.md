# Product refinement evidence

This package supports [architecture revision 3](../../docs/architecture/21_SparkX_2_6_4B_Consolidated_Architecture_and_MiniCPM_Validation.md).

`repository_snapshot.json` records evidence inspected before editing the canonical plan, including its prior hash and the then-current Git state. `evidence.json` records public source URLs, retrieved hashes and reading scopes; temporary source files are not required for using the plan. `analytical_costs.json` is regenerated by `estimate_costs.py` using the previously collected Spark tensor headers, without loading a model. `validation.json` records the documentation/evidence/arithmetic audit performed by `validate_report.py`.

[Follow-up snapshot](followup_snapshot.json) reconciles concurrent changes through commit `023e8b9`: authenticated historical vision-score replay and the new production fused-AdamW integration. It preserves the first smoke attempt's reporting error without interpreting that error as optimizer divergence or a sustained-training pass. This is a timestamped observation; subsequent implementation work does not rewrite it.

These checks validate artifacts and consistency. They are not new model tests, reproductions of paper benchmarks, native audio qualification, or evidence of visual reasoning, learning or RSI. Existing experiment outcomes remain unchanged. Current execution protocols continue to control actual runs.

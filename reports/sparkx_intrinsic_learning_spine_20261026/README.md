The latest user clarification is incorporated: full offline fine-tuning establishes multimodal perception and reasoning, including the native sensory/spatial/temporal components. Self-learning subsequently acquires knowledge and experience using those trained abilities. It is not the plan for teaching an untrained modality path to work.

The design also corrects the prior conflation of intrinsic memory and peripheral attachment. Memory attention, associative parameters and persistent plastic knowledge are native model components. The separate spine carries additional sensory/model features, observer readouts and action-head inputs. Learning in persistent dynamic parameters does not require the stable 4B weights to change.

No training jobs, model-weight downloads, model-source imports, device actions or commits were performed. Existing rejected vision/memory capability results retain their disposition. Earlier dated validation receipts remain tied to their historical revisions.

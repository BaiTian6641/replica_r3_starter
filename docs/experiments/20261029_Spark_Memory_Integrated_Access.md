tensors. The response objective reaches the contextual producer and active readers,
including early readers through later frozen blocks. Initially zero output
projections intentionally block producer gradients; after those projections update,
the producer receives gradients. Durable serialization, inference values and
checkpoint export detach. No NumPy, hashing or disk round-trip carries the training
gradient. Producer identities authenticate stored values independently of that graph.

reader count adds access computation and parameters, not searches, writes or copies.

time, source revision, correction/revocation and generation. This candidate keeps
no projected K/V cache; projections are recomputed from current validated values,
so a stale projection cannot bypass invalidation. Frozen producer releases are
required for durable inference. Fitting can re-encode still-valid canonical text
from an earlier producer release; it cannot treat stale durable slots as current.

## Scope, initialization and code boundaries

All native model work uses the **Mac Studio M2 Ultra MPS GPU**, FP32, microbatch
one, accumulation eight, nonreentrant activation checkpointing and CPU fallback
disabled. File audits run on CPU without model construction. D2 trains all
**2,516,756,480 original parameters in 381 tensors**, including embeddings/head,
and **895,490 added parameters in 48 tensors**. No original layer is frozen.

The small added path retains 64-wide memory/workspace, four slots, two workspace
steps, four heads and final-block insertion. Source text remains in the native
prompt and support branch. Generation uses the qualified uncached route with
support/workspace fixed from the original request throughout an answer.

Each new length and the tiny run starts from the same local sealed MiniCPM5-2B
revision `f97400052a43d642bbc6e9975e2397e3ae6a6b52`, seed 17. It does not start
from a selected D0/D1 result. Original Muon/AdamW peak rates are 1e-4; new-module
peak rates are 1e-3, with two warmup updates, constant schedule and zero decay.
Muon uses experimental block-2048 int8 momentum, momentum .95, five FP32
Newton–Schulz steps and no Nesterov. These are diagnostic settings, not a fair
architecture-rate screen.

The historical 256 pair keeps its original code/receipt binding at `9bc719b`.
Its two contracts agree with each other. Subsequent storage-aware code changes
are explicitly pinned for the new runs; the old receipts are not rewritten or
presented as current-code resumes. A continuation must retain its own exact
source/data/settings/packages/implementation contract. Native completed-update
restart does not establish full-size uninterrupted-versus-split numerical
equivalence.

The [offline preflight](../../reports/D2_resume_preflight_20261022.json) verified
nine sealed selected-inventory files and MPS availability without instantiating
a model or downloading weights. Launches set Hugging Face, Transformers
and datasets offline, disable telemetry and record local source reuse. The

## Resource and interpretation boundaries

One full-size MPS job runs at a time. The driver guard stops at a sampled
40 GiB limit; host checks stop after three samples at 512 MiB swap growth or
at/below 15% reported free memory. Driver sampling is .25 seconds and host
sampling two seconds. Sampled guards can miss transients; RSS and driver memory
overlap and must not be added.

The launch plan requires **80 GiB free before a 512 stage and 110 GiB before a
tiny stage**. Capacity pairs may add about 52 GB of logical checkpoint/export
data. Ordinary serialization and temporary copies still consume space; APFS
sharing applies only after complete byte verification and does not share
different learned snapshots or optimizer/RNG payloads. No physical saving is
inferred from logical duplicate sizes. No new evidence deletion is implied.

This tiny-fit pass establishes only bounded D2 learning/generation
infrastructure on this diagnostic. Useful memory/recurrence gain, fair D0/D1/D2
controls, independent family transfer, retention, selected/frozen architecture,
learned practice selection, authentic Replica fidelity, VLM/ANE execution and
Blackwell residency remain separate gates. No model is promoted by this record.

# Spark research cross-check and conditional alignment experiment

31 October 2026. Primary-source inspection for the V17 qualification and V18.2 repair task. These are paper descriptions and adaptation hypotheses, not reproduced Spark results. No mechanism or training run is added to V18.2.

Training loss or validation NLL alone cannot determine promotion.

## One conditional follow-up if corrected native V18 fails

The CPU fixture's endpoint is not the native V18 decision. Only after the corrected native comparison completes validly and fails its fixed endpoint would the following **single alignment experiment** be eligible for a separate protocol review. It is proposed, not selected for execution or included in the V18 budget.

Hypothesis: the existing slots retain task-relevant information, but the producer-to-reader interface was optimized for the V16 teacher-KL distribution and is poorly aligned to complete-answer decoding. Test one loss change on a fresh synthetic fitting corpus with new entities, seeds and questions: **direct answer-plus-EOS CE versus the existing top-64 teacher KL**, updating the same producer, reader and gates in both arms. Start both from the same pinned V16 state and inherited moments. Use NativeFusedAdamW, sites 3/7, content keys, identical slots, precision, exposure, pair batching, 128 steps and per-world token normalization. No moment reset, routing change, extra capacity or new memory path. Qualification must precede either arm; a failure stops both.

Declare all fitting pairs, disjoint fitting diagnostics, update order and budgets before execution. Assess only the terminal state; preserve intermediate trajectories without selecting a prefix. Primary support requires CE to improve mean final pair-minimum complete-response margin over KL, with no larger count of worlds below baseline and no loss of complete-answer correctness. Also require a positive contextual-versus-wrong/absent gap and report absolute full-vocabulary correctness; a merely less-negative margin is insufficient for useful-recall promotion. No development opening is bundled with this comparison.

Distinguish explanations with fixed, charged diagnostics in both arms: exact-text competence establishes whether the frozen decoder can solve the task; frozen-feature and slot probes use original held-out group identities and matched shuffled labels; live-reader predictions measure access through the real decoder. Stronger slot probes with weak decoder responses support an alignment limitation, but do not prove a lossless code. Failure of a linear probe alone does not prove compression loss. Consistent loss between qualified frozen features and compressed slots across predeclared reconstruction and task probes would justify considering compression later. It does not authorize a capacity or routing change here. Any reconstruction diagnostic is evidence, not an extra reconstruction training arm.

## Progression remains gated

Qualified recall → completed-interaction formation → source-free persistent learning → correction/retention/rollback → all-layer and nested-learning evaluation → RSI.

Exactly-once causal chunk formation is a separate substage of formation. Deleting a source or excluding it from fresh retrieval does not prove removal of information already learned into P. All-layer CPU plumbing is engineering evidence until qualified behavioral and total-cost comparisons exist. Approved identity, evaluation authority and the Spine's external-component role remain separate from learned memory. No multimodal, capacity, P-promotion, density or RSI gate changes in this repair task.

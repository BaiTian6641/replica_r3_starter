**Status:** `awaiting_authentic_source_records`. **Dependencies:** none; can start independently.

Use the existing interview worksheet to collect real decisions, alternatives, information available then, constraints, reasons, sacrificed tradeoffs and decisive counterfactuals. Preserve original spans, uncertainty, dates and separate allowed uses; never fabricate missing personal history.

- **Artifact:** templates/replica_interview.md; planned: private authentic source archive and consent/lineage manifest.
- **Interface:** Human source statement/document -> confirmed source record -> topic/decision family -> permitted retrieval/training/evaluation use. Assistant inference remains a proposed inference.
- **Test gate:** Each record traces to authentic source testimony with allowed use; source facts, later interpretation, hypothetical, synthetic persona and agent experience are distinct. Complete decision families are split before variants.
- **Resources:** Human-source collection in short sessions; start 5–10 independent cases, grow toward proposed 30–100. Private source files stay local and out of default Git/public logs.
- **Failure policy:** Leave unknown fields blank/unknown. Continue generic architecture work independently; no synthetic biography substitutes for source input.
- **Next smallest task:** Prepare a local intake record for the first real decision and request/consume source material only when the human supplies it.

## R2 — Measure evidence-conditioned Replica baselines

**Status:** `pending`. **Dependencies:** R1, S1.4.

Before personal tuning, compare generic, approved-summary and archive-retrieval systems on sealed source decisions and unknown biography. Include decisive versus irrelevant counterfactual changes and repeated human choices to estimate reference variability.

- **Artifact:** planned: held-out decision protocol and blinded review packet; planned: factual/decision/process/temporal fidelity baseline.
- **Interface:** Evaluator-owned decision cases + same available source information -> randomized blinded systems -> source review and objective factual checks.
- **Test gate:** Choice/ranking, information requests, rationale fit, unknown handling, time and ownership scored separately. Report raw agreement and human test-retest variability; no percentage-of-person claim.
- **Resources:** Small human review sessions; fixed inference budget and source exposure across systems. Hold out topic/decision families, not paraphrases.
- **Failure policy:** Do not tune on reviewed final cases. If a source changes their view or both choices are plausible, preserve that outcome rather than forcing a label.
- **Next smallest task:** Reserve complete decision families for evaluation before producing any teacher expansion.

## R3 — Test decision conditioning and internal memory separately from style

**Status:** `pending`. **Dependencies:** R2, S2.5.

Train a small source-grounded preference/reader candidate with general replay. Compare plain full tuning and augmented tuning on the same authentic decisions where appropriate. Keep optional voice/style adaptation separate from source facts and conditional priorities.

- **Artifact:** planned: personal candidate manifest and mixture audit; planned: blinded decision/factual/retention/style comparison.
- **Interface:** Confirmed train-role decisions -> bounded derived targets -> candidate trainer -> independent fidelity and competence evaluator. Every derivative retains its original decision group.
- **Test gate:** Useful held-out conditional decision fidelity beyond evidence-only baseline without material competence loss or invented autobiography. Style similarity alone does not pass; repeating a tiny archive does not create independent evidence.
- **Resources:** Low initial personal mixture share or separable adapter; bounded epochs/rates selected on development. Exact training scope labelled full_text, modules_only or adapter.
- **Failure policy:** If evidence-only baseline explains gains, retain it and report the personal neural update as unproven. Correct unsupported targets rather than training harder.
- **Next smallest task:** Choose one confirmed conditional principle and test unseen related situations before expanding the personal mixture.

## R4 — Evaluate a developing parallel Replica over time

**Status:** `pending`. **Dependencies:** R3, S3.5.

Combine one authentic conditional priority with one independently verified technical skill, then follow source_current and parallel_replica branches through chronological learning. Trace every divergence to a source revision or agent event.

- **Artifact:** planned: branch comparison and provenance history; planned: longitudinal fidelity/competence/rollback report.
- **Interface:** Versioned identity snapshot + accepted skill manifest + branch event journal -> later tasks -> factual, decision and technical outcome evaluators.
- **Test gate:** The system applies a learned procedure to new values/compositions, retains source attribution and handles real preference changes. General correctness and faithful prediction of a source belief remain separate dimensions.
- **Resources:** Reuse the ten-cycle infrastructure; schedule source review only for meaningful new material. Extend horizon only after initial stable evidence.
- **Failure policy:** Preserve and explain legitimate branch divergence; do not rewrite human source records to match agent development or force agreement.
- **Next smallest task:** Create one unseen microengineering task where the approved conditional priority changes a valid planning choice.
